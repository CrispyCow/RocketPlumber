Tamzen Regular and Bold by Suraj N. Kurapati, derived from Tamsyn by Scott Fial.
The eight bundled TTFs are unmodified assets from the
[upstream repository](https://github.com/sunaku/tamzen-font), pinned at commit
`3255e8259bc9b880c60ab8b737ec8aa574e00d75`. See the bundled [LICENSE](LICENSE).

The upstream TTFs have limited Latin-1 coverage. Current static game text and
units use ASCII plus `×`, all covered in both weights. Greek delta and the micro
sign are absent; existing `delta-V` wording is retained and no fallback family is
registered. New UI symbols need a coverage check.
